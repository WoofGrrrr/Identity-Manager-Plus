Identity Manager Plus for Thunderbird

Welcome to version 25.3.31 of Identity Manager Plus, the initial release.

Identity Manager Plus makes managing and using your Thunderbid Account Identities just a bit easier.

It started out as a small enhancement to the original Identity Chooser MX add-on, with some UI enhancements so that I could add the ability to sort my Identities by email address, but then I went on from there.

Identity Manager Plus includes these features from Identity Chooser MX:

  • It displays an Identity Chooser Pop-Up Menu when you compose a new email, where you choose an Identity to use for the From email address.
  • On the extension's Options Page:
    • You can use drag-and-drop to specify the order in which your Identities are listed on the Identity Chooser Pop-Up Menu.
    • For each Identity, you can click a check-box to NOT Include that Identity on the Identity Chooser Pop-Up Menu.
    • You can chose when the Identity Chooser Pop-Up Menu is displayed:
      • When you are composing a New Message
      • When you are Replying to a Message
      • When you are Forwarding a Message
      • When you are opening a Draft Messsage
    • It integrates with the BorderColors D add-on (more below.)

    Identity Mananger Plus adds these features:

    • On the extension's Options Page:
      • You can select one or more Identities and click a button to MOVE those Identities to the Top or to the Bottom of the list.
      • You can sort your Identities using criteria that you select:
        • By Name
        • By Email Address
        • By Email Address Domain
        • By Email Address Host Name
        • In Ascending Order
        • In Descending Order

      • For each Identity, you can click a button to LOCK that Identity at its current position in the Identity Chooser Pop-Up Menu.

        Sorting the list or moving other Identies to the Top or to the Bottom of the list will NOT move these Locked Identities.

        (Because of the way that drag-and-drop works, it does not prevent a locked Identity from being moved when you move a different Identity above, below, or on top of it. I am looking for a solution to this.)

      • There is an option to choose what happens when you simply close the Identity Chooser Pop-Up Menu without choosing an Identity. The default is to close the New Message Window as well. But there is an option to leave the New Message Window open and just use the default Identity as configured by Thunderbird.
      • On the Indentity Chooser Pop-Up Menu, it adds a Use Default button in addition to the Cancel button. This button simply closes the Identity Chooser Pop-Up Menu so that the New Message Window will use the default From email address as configured by Thunderbird.
      • You can edit or delete and Identities or create new ones directly on the Options Page.
      • There is an option to create a new Identity when sending an email and none of your existing Identities has the email's From email address.

How does it work?

Whenever you open an New Message Window to write a new email, reply to a message in your inbox or forward something to a friend, Identity Chooser will open a window to allow you to choose your sender address before it continues access the New Message Window.

This workflow works every time and everywhere when Thunderbird opens a new message. This means that the Identity Chooser doesn't work only in the main window, it is also active when you create a new email directly out of the address book, for instance.

Configuration

Identity Manager Plus is very configurable:

  • It lets you decide when it is active (Compose, Reply, Forward, and/or Draft)
  • You can you arrange the order of your Identities the way you want
  • You can hide the Identities you don't want to see in the Identity Choose Pop-Up Window

If you want to show a colorful border around the New Message Window so that you can readily know which Identity you are sending your email from, I recommend the add-on BorderColors D .

Identity Manager Plus detects an installed copy of BorderColors D and integrates with it. In the list of Identities on the Identity Chooser Pop-Up Menu and on the Identity Manager Plus Condiguration Page, the configured border color from BorderColors D for each Identity is displayed as a small, colored "dot".
